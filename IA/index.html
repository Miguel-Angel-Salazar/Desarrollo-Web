Resumen de aprendizaje

A continuación se presenta una guía sencilla sobre los conceptos básicos que se usan en esta página.

Etiquetas HTML

Las etiquetas son los elementos básicos que estructuran una página web. Por ejemplo:

  • <html>: indica que el documento es HTML.
  • <head>: contiene información del documento.
  • <body>: contiene el contenido visible.
  • <h1>: define un título principal.
  • <p>: crea un párrafo.
  • <ul> y <li>: crean listas.

Atributos

Los atributos agregan información o comportamiento a las etiquetas. Algunos ejemplos son:

  • lang: define el idioma del documento.
  • charset: indica la codificación de caracteres.
  • href: asigna un enlace a una etiqueta <a>.
  • src: define la ruta de una imagen.
  • alt: describe una imagen cuando no se visualiza.
  • class: identifica un grupo de elementos para aplicar estilos.

CSS

CSS es el lenguaje para dar estilo a una página web. Permite controlar colores, tamaños, márgenes y diseño.

  • color: cambia el color del texto.
  • background: define el fondo de un elemento.
  • font-family: establece la fuente.
  • margin: separa un elemento del exterior.
  • padding: agrega espacio interno.
  • border-radius: redondea los bordes.
  • display: controla cómo se organiza un elemento.
